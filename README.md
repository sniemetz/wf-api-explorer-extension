# Workfront API Explorer

Chrome extension (Manifest V3). Shows Workfront API object metadata.

- Spec: `docs/spec.md`
- Plan: `docs/superpowers/plans/2026-11-14-wf-api-explorer.md`

## Install (load unpacked)

1. Open `chrome://extensions`.
2. Turn on Developer mode.
3. Click "Load unpacked" and select the `extension/` folder.
4. Optional: turn on "Allow in Incognito" for the extension to use the cache in incognito windows.

## Test

`npm test` (Node 24, `node --test`).
